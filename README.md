# 🏢 Умный офис

Учебный проект по виртуализации, сетевым технологиям и автоматизации.

## 📌 О проекте

Цель проекта — создать виртуальный прототип сети офиса в GNS3.

В проекте реализованы:
- Сетевая инфраструктура с использованием VLAN.
- Маршрутизация между подсетями.
- Виртуальные серверы на базе РЕД ОС 8.
- Развёртывание сервисов с помощью Docker.
- Сбор показаний виртуальных датчиков температуры и влажности.
- Автоматизация и передача данных с помощью Node-RED.

# 🌐 Практическая работа №2
## Настройка виртуальной сети в GNS3

### Цель
Настроить сетевое оборудование, VLAN и обеспечить связь между рабочей станцией и серверами.

### Выполненные задачи
- Запущены Cisco SW и Cisco RTR.
- Добавлены четыре виртуальные машины РЕД ОС 8 и Windows Server 2019.
- Созданы три VLAN на коммутаторе.
- Настроены access-порты.
- Настроен trunk между коммутатором и маршрутизатором.
- Настроен адрес управления коммутатором.
- Настроены шлюзы для каждой VLAN на маршрутизаторе.
- Выполнена IP-адресация с маской /26.

### Проверка
- WIN-01 достигает IOT-01.
- WIN-01 достигает трёх серверов РЕД ОС.
- IOT-01 достигает серверов РЕД ОС.

### Результат
Создана виртуальная офисная сеть с разделением на VLAN и настроенной маршрутизацией между подсетями.

# 📡 Практическая работа №4
## Node-RED и виртуальные датчики

### Цель
Развернуть Node-RED на IOT-01, создать виртуальные датчики и настроить автоматическую передачу показаний на CTRL-01.

### Выполненные задачи
- Запущен Node-RED через Docker Compose.
- Настроен доступ к интерфейсу через порт 1880.
- Создан виртуальный датчик температуры TEMP-01.
- Создан виртуальный датчик влажности HUM-01.
- Настроена автоматическая генерация показаний каждые 5 секунд.
- Настроена передача данных методом HTTP POST.
- Настроен приёмник данных на CTRL-01.

### Схема потока Node-RED

Inject → Change → HTTP Request

### Параметры датчиков

| Датчик | Назначение | Единица измерения |
|---|---|---|
| TEMP-01 | Температура | °C |
| HUM-01 | Влажность | % |

### Формат передачи данных

Данные передаются в формате JSON.

Пример:

json {
  "status": "ok",
  "sensor_id": "TEMP-01",
  "value": 24
}
### Проверка
- Node-RED открывается на WIN-01.
- Датчики формируют показания автоматически.
- Интервал отправки составляет 5 секунд.
- CTRL-01 получает данные от обоих датчиков.
- Передача осуществляется по HTTP POST.

### Результат
Создана система виртуальных датчиков температуры и влажности. Настроена автоматическая отправка показаний с IOT-01 на CTRL-01.
