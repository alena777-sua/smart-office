# Умный офис

## Цель проекта
Создать виртуальный прототип сети офиса в GNS3.
В Node-RED моделируются температура, влажность и вентилятор.
Охлаждение включается автоматически при повышении
температуры; администратор может наблюдать за состоянием
и управлять вентилятором вручную.

## Данные студента
Номер в журнале: ВПИШИТЕ СВОЙ НОМЕР

## Устройства
- WIN — Windows Server 2019, место администратора.
- CTRL — РЕД ОС 8, управляющий узел.
- MON — РЕД ОС 8, узел мониторинга.
- DB — РЕД ОС 8, узел хранения данных.
- IOT — РЕД ОС 8, Node-RED и модели TEMP, HUM, FAN.
- Cisco SW — сетевой коммутатор.
- Cisco RTR — маршрутизатор и шлюз сети.
