# 🏢 Умный офис

Учебный проект по виртуализации, сетевым технологиям и автоматизации.

## О проекте

Цель проекта — создать виртуальный прототип офисной сети в GNS3, объединить серверы в единую инфраструктуру и настроить сбор и обработку данных от виртуальных датчиков.

В проекте используются VLAN, маршрутизация, РЕД ОС 8, Windows Server 2019, Docker, Node-RED, виртуальные датчики и автоматическое управление вентилятором.

| Устройство | Назначение |
|---|---|
| WIN-01 | Рабочее место администратора |
| CTRL-01 | Управляющий сервер |
| MON-01 | Сервер мониторинга |
| DB-01 | Сервер базы данных |
| IOT-01 | Node-RED и виртуальные датчики |
| SW | Коммутатор |

# Практическая работа №1. Создание виртуальной инфраструктуры

Цель: создать виртуальный прототип офисной сети в GNS3.

Выполнено: создана виртуальная инфраструктура, развёрнуты необходимые виртуальные машины, подготовлены серверы и сетевое оборудование.

Результат: подготовлена среда для последующей настройки сети и сервисов.

---

# Практическая работа №2. Настройка виртуальной сети в GNS3

Цель: настроить VLAN, маршрутизацию и связь между рабочей станцией и серверами.

Выполнено: запущены Cisco SW и Cisco RTR, добавлены виртуальные машины РЕД ОС 8 и Windows Server 2019, созданы три VLAN, настроены access- и trunk-порты, шлюзы и IP-адресация с маской /26.

Результат: создана офисная сеть с разделением на VLAN и маршрутизацией между подсетями.

---

# Практическая работа №3. Docker, SSH, SCP и Nginx

Цель: подготовить серверы РЕД ОС 8 к запуску сервисов и развернуть Nginx.

Выполнено: установлены Docker и Docker Compose на CTRL-01, DB-01 и IOT-01, настроен SSH между серверами, выполнена передача файлов через SCP, запущен Nginx через Docker и проверена его доступность по HTTP.

Результат: подготовлена среда для запуска контейнеров и развёрнут веб-сервер Nginx.

---

# Практическая работа №4. Node-RED и виртуальные датчики

Цель: развернуть Node-RED на IOT-01 и настроить передачу показаний датчиков на CTRL-01.

Выполнено: Node-RED запущен через Docker Compose, настроен доступ через порт 1880, созданы виртуальные датчики TEMP-01 и HUM-01, настроена генерация показаний и передача данных методом HTTP POST.

Результат: создана система виртуальных датчиков с передачей показаний на управляющий сервер.

---

# Практическая работа №5. Автоматическое управление вентилятором

Цель: настроить автоматическое управление вентилятором FAN-01 по показаниям датчика температуры TEMP-01.

Выполнено: в Node-RED создана логика управления вентилятором, настроено включение при температуре выше 30 °C и выключение при температуре ниже 30 °C, подготовлена передача команд на CTRL-01 через HTTP POST.

Результат: подготовлена система автоматического управления вентилятором в зависимости от температуры.

---

# Практическая работа №6. Хранение данных датчиков в SQLite

Цель: организовать сохранение показаний виртуальных датчиков и событий управления вентилятором на DB-01.

Выполнено: подготовлена база данных SQLite, организовано сохранение показаний TEMP-01 и HUM-01, а также событий исполнительного устройства FAN-01.

Результат: создано централизованное хранилище показаний датчиков и событий управления.

---

# Практическая работа №7. Мониторинг умного офиса с Prometheus и Grafana

Цель: установить и настроить Prometheus и Grafana для мониторинга серверов и виртуальных датчиков.

Выполнено: установлены Prometheus и Grafana на MON-01, настроен сбор метрик приложения CTRL-01, подключён Prometheus к Grafana, подготовлена панель мониторинга температуры, влажности и состояния вентилятора, созданы правила оповещения и настроена отправка уведомлений на электронную почту. Проверена отправка тестового письма Grafana.

Результат: подготовлена система мониторинга умного офиса с визуализацией 
показателей и email-оповещениями.
