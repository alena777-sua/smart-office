#Работа 1.Умный офис
#Цель проекта
Создать виртуальный прототип сети офиса в GNS3. В Node-RED моделируются температура, влажность и вентилятор. Охлаждение включается автоматически при повышении температуры; администратор может наблюдать за состоянием и управлять вентилятором вручную.
Данные студента
#Номер в журнале: 19
#Устройства
WIN — Windows Server 2019, место администратора.
CTRL — РЕД ОС 8, управляющий узел.
MON — РЕД ОС 8, узел мониторинга.
DB — РЕД ОС 8, узел хранения данных.
IOT — РЕД ОС 8, Node-RED и модели TEMP, HUM, FAN.
Switch SW — сетевой коммутатор.
РЕД ОС 8 RTR — маршрутизатор и шлюз сети.
#Файлы
schemes/ — план помещения и схема сети.
docs/ — таблица адресов и портов.
evidence/ — доказательства проверок.
journal.md — журнал работы.

#Работа 2. Сборка виртуальной сети офиса в GNS3
#Цель работы
Собрать виртуальную сеть офиса в GNS3, настроить сетевое оборудование, создать VLAN и обеспечить связь между рабочей станцией и серверами.
Выполненные задачи
Создан проект виртуальной сети в GNS3.
#Добавлены и запущены устройства:


Cisco SW;
Cisco RTR;
четыре виртуальные машины РЕД ОС 8;
Windows Server 2019.
На Cisco SW созданы три VLAN.
Настроены access-порты и trunk-соединение с маршрутизатором.
Настроен адрес управления коммутатором в VLAN серверов.
На Cisco RTR настроены шлюзы для каждой VLAN.
Настроена адресация устройств 192.168.XX.X с маской /26 согласно таблице адресации из практической работы №1.
Проверка работоспособности
Проведена проверка сетевой доступности:
WIN-01 достигает IOT-01.
WIN-01 достигает трёх серверов РЕД ОС.
IOT-01 достигает серверов РЕД ОС.
Результат работы
Создана виртуальная сеть офиса в GNS3. Настроены VLAN, access- и trunk-порты, маршрутизация и адресация устройств.
Конфигурации оборудования и результаты проверок сохранены в репозитории.

#Работа 3. Подготовка серверов и развёртывание Nginx
#Цель работы
Подготовить серверы на базе РЕД ОС 8 к запуску сервисов, установить Docker и Docker Compose, настроить SSH и SCP, а также развернуть тестовый веб-сервер Nginx на CTRL-01.
#Выполненные задачи
На CTRL-01, DB-01 и IOT-01 установлены и настроены Docker и Docker Compose.
Настроен доступ по SSH внутри сети GNS3.
Выполнена передача тестового файла с IOT-01 на CTRL-01 с помощью SCP.
На CTRL-01 выполнен запуск Nginx двумя способами:


через docker run;
через Docker Compose.
Проверена доступность веб-сервера по HTTP.
На WIN-01 открыта стартовая страница Nginx.
Проверка работоспособности
Для проверки использовались:
docker ps — просмотр запущенных контейнеров.
docker logs — просмотр журналов контейнеров.
curl — проверка HTTP-доступности.
ssh — подключение к удалённым серверам.
scp — передача файлов между серверами.
В браузере WIN-01 открыта стартовая страница Nginx с сообщением Welcome to nginx!.
Результат работы
Подготовлены серверы для работы с Docker и Docker Compose. Развёрнут тестовый веб-сервер Nginx. Проверена его доступность из сети.
Создан учебный файл compose.yml. Конфигурации и результаты проверок сохранены в репозитории.

#Работа 4. Настройка Node-RED и виртуальных датчиков
#Цель работы
Развернуть Node-RED на сервере IOT-01, создать виртуальные датчики температуры и влажности и настроить автоматическую передачу показаний на сервер CTRL-01.
Выполненные задачи
На IOT-01 установлен и запущен Node-RED с использованием Docker Compose.
Настроен доступ к веб-интерфейсу Node-RED с компьютера WIN-01 через порт 1880.
Созданы два виртуальных датчика:


TEMP-01 — датчик температуры.
HUM-01 — датчик влажности.
Настроена автоматическая генерация случайных значений датчиков.
Установлен интервал формирования показаний — каждые 5 секунд.
Настроена отправка данных с IOT-01 на CTRL-01 с использованием HTTP POST.
На CTRL-01 запущен приёмник данных через Docker Compose.
Проверено получение показаний от обоих датчиков.
Настройка Node-RED
В Node-RED создан поток обработки данных.
Используются следующие узлы:
Inject — автоматический запуск формирования показаний.
Change — изменение и формирование параметров сообщения.
HTTP Request — отправка показаний на сервер CTRL-01.
Debug — просмотр результатов выполнения потока.

Проверка работоспособности
Открыт интерфейс Node-RED с компьютера WIN-01.
Запущен поток формирования показаний.
Проверена автоматическая отправка данных с интервалом 5 секунд.
На CTRL-01 проверено получение показаний температуры и влажности.
В консоли CTRL-01 просмотрены поступающие JSON-сообщения.
Результат работы
На сервере IOT-01 настроен Node-RED. Созданы два виртуальных датчика температуры и влажности. Настроена автоматическая генерация случайных показаний и передача данных на CTRL-01.
Приёмник на CTRL-01 получает показания обоих датчиков. Передача данных осуществляется по HTTP.
