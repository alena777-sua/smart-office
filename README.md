# 🏢 Умный офис

Учебный проект по виртуализации, сетевым технологиям и автоматизации.

## 📌 О проекте

Цель проекта — создать виртуальный прототип офисной сети в GNS3.

В проекте реализованы:
- Сетевая инфраструктура с использованием VLAN.
- Маршрутизация между подсетями.
- Виртуальные серверы на базе РЕД ОС 8.
- Развёртывание сервисов с помощью Docker.
- Сбор показаний виртуальных датчиков температуры и влажности.
- Автоматизация и передача данных с помощью Node-RED.
- Автоматическое управление вентилятором по показаниям температуры.

# 📡 Практическая работа №4

## Node-RED и виртуальные датчики

### Цель

Развернуть Node-RED на IOT-01, создать виртуальные датчики и настроить автоматическую передачу показаний на CTRL-01.

### Выполненные задачи

- Запущен Node-RED через Docker Compose.
- Настроен доступ к интерфейсу через порт 1880.
- Создан виртуальный датчик температуры TEMP-01.
- Создан виртуальный датчик влажности HUM-01.
- Настроена автоматическая генерация показаний каждые 5 секунд.
- Настроена передача данных методом HTTP POST.
- Настроен приёмник данных на CTRL-01.

### Схема потока Node-RED

Inject → Change → HTTP Request

### Параметры датчиков

| Датчик | Назначение | Единица измерения |
|---|---|---|
| TEMP-01 | Температура | °C |
| HUM-01 | Влажность | % |

### Формат передачи данных

Данные передаются в формате JSON.

Пример:

json {
  "status": "ok",
  "sensor_id": "TEMP-01",
  "value": 24
}
### Проверка

- Node-RED открывается на WIN-01.
- Датчики формируют показания автоматически.
- Интервал отправки составляет 5 секунд.
- CTRL-01 получает данные от обоих датчиков.
- Передача осуществляется по HTTP POST.

### Результат

Создана система виртуальных датчиков температуры и влажности. Настроена автоматическая отправка показаний с IOT-01 на CTRL-01.

# 🌀 Практическая работа №5

## Автоматическое управление вентилятором

### Цель

Создать в Node-RED автоматическое управление вентилятором по показаниям датчика температуры TEMP-01.

### Условие работы

- Если температура выше 30 °C — вентилятор включается (ON).
- Если температура ниже 30 °C — вентилятор выключается (OFF).
- Для каждого состояния используется отдельный узел change.
- Команда передаётся на CTRL-01 методом HTTP POST.

### Схема потока

TEMP-01 → Switch → FAN ON / FAN OFF → HTTP Request → Debug

### Выполненные задачи

- Создан узел switch для проверки температуры.
- Настроено условие сравнения значения температуры с 30 °C.
- Созданы две ветки: FAN ON и FAN OFF.
- Для включения и выключения вентилятора созданы отдельные узлы change.
- Настроены параметры команды вентилятора.
- Настроен HTTP Request для отправки команды на CTRL-01.
- Добавлен Debug для проверки отправляемых сообщений.

### Параметры вентилятора

| Поле | Значение |
|---|---|
| fan.state | ON или OFF |
| fan.actuator_id | FAN-01 |
| fan.zone | server_room |
| fan.mode | auto |
| fan.timestamp | Время формирования команды |

### Пример команды включения

json {
  "fan": {
    "state": "ON",
    "actuator_id": "FAN-01",
    "zone": "server_room",
    "mode": "auto",
    "timestamp": 1794560000000
  }
}
Для выключения вентилятора значение fan.state меняется на OFF.

### Настройки HTTP Request

| Параметр | Значение |
|---|---|
| Method | POST |
| URL | http://192.168.20.11:8080/api/actuators |
| Return | Parsed JSON object |
| Content-Type | application/json |

### Проверка работы

| Температура | Ожидаемое состояние |
|---|---|
| 31 °C | ON |
| 35 °C | ON |
| 29 °C | OFF |
| 20 °C | OFF |

Поведение при ровно 30 °C необходимо определить отдельно, поскольку в условии задания оно не указано.

### Результат

Подготовлена логика автоматического управления вентилятором по показаниям датчика температуры TEMP-01. Реализованы две ветки управления — включение и выключение вентилятора.

Для завершения работы необходимо проверить корректность HTTP-приёмника на CTRL-01 и убедиться в успешной передаче команд ON и OFF.
