# 🏢 Умный офис

Учебный проект по виртуализации, сетевым технологиям и автоматизации.

## О проекте

Цель проекта — создать виртуальный прототип офисной сети в GNS3, объединить серверы в единую инфраструктуру и настроить сбор и обработку данных от виртуальных датчиков.

В проекте предусмотрены VLAN, маршрутизация между подсетями, виртуальные серверы РЕД ОС 8 и Windows Server 2019, Docker, датчики температуры и влажности, Node-RED и автоматическое управление вентилятором.

# Практическая работа №1. Создание виртуальной инфраструктуры

Цель: создать виртуальный прототип офисной сети в GNS3.

Выполнено:
- Создана виртуальная инфраструктура.
- Развёрнуты необходимые виртуальные машины.
- Подготовлены серверы и сетевое оборудование.

Результат: подготовлена среда для последующей настройки сети и сервисов.

---

# Практическая работа №2. Настройка виртуальной сети в GNS3

Цель: настроить VLAN, маршрутизацию и связь между рабочей станцией и серверами.

Выполнено:
- Запущены Cisco SW и Cisco RTR.
- Добавлены виртуальные машины РЕД ОС 8 и Windows Server 2019.
- Созданы три VLAN.
- Настроены access- и trunk-порты.
- Настроены шлюзы для VLAN.
- Выполнена IP-адресация с маской /26.

Проверка: проверялась связность WIN-01 с серверами и IOT-01.

Результат: создана офисная сеть с разделением на VLAN и маршрутизацией между подсетями.

---

# Практическая работа №3. Docker, SSH, SCP и Nginx

Цель: подготовить серверы РЕД ОС 8 к запуску сервисов и развернуть Nginx на CTRL-01.

Выполнено:
- Установлены Docker и Docker Compose на CTRL-01, DB-01 и IOT-01.
- Настроен SSH между серверами.
- Выполнена передача тестового файла через SCP.
- Запущен Nginx через docker run и Docker Compose.
- Проверялась доступность веб-сервера по HTTP.

Результат: развёрнут тестовый веб-сервер Nginx.

---

# Практическая работа №4. Node-RED и виртуальные датчики

Цель: развернуть Node-RED на IOT-01 и настроить передачу показаний на CTRL-01.

Выполнено:
- Node-RED запущен через Docker Compose.
- Настроен доступ через порт 1880.
- Подготовлены виртуальные датчики TEMP-01 и HUM-01.
- Настроена генерация показаний.
- Настроена передача данных методом HTTP POST.
- Подготовлен HTTP-приёмник на CTRL-01.

Параметры датчиков:

| Датчик | Назначение | Единица | Зона |
|---|---|---|---|
| TEMP-01 | Температура | °C | server_room |
| HUM-01 | Влажность | % | work_area |

Пример сообщения датчика:

json {
  "sensor_id": "TEMP-01",
  "zone": "server_room",
  "unit": "C",
  "value": 24,
  "timestamp": 1794560000000
}
Результат: подготовлена система виртуальных датчиков и передача показаний с IOT-01 на CTRL-01.

---

# Практическая работа №5. Автоматическое управление вентилятором

Цель: настроить автоматическое управление вентилятором по показаниям датчика температуры TEMP-01.

Выполнено:
- Настроен узел switch для проверки температуры.
- Созданы ветки FAN ON и FAN OFF.
- Для каждой ветки настроен отдельный узел change.
- Подготовлена отправка команд на CTRL-01 через HTTP POST.
- Добавлен узел debug для проверки результата.

Условие работы:
- Выше 30 °C — вентилятор включается (ON).
- Ниже 30 °C — вентилятор выключается (OFF).

Текущий статус: логика управления настроена, требуется завершить проверку HTTP-приёмника.

Результат: подготовлено автоматическое управление вентилятором по показаниям датчика температуры.
