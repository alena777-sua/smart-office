# 🏢 Умный офис

Учебный проект по виртуализации, сетевым технологиям и автоматизации.

## 📌 О проекте

Цель проекта — создать виртуальный прототип сети умного офиса в GNS3.

В проекте реализованы:
- Сетевая инфраструктура с использованием VLAN.
- Маршрутизация между подсетями.
- Виртуальные серверы на базе РЕД ОС 8.
- Рабочая станция Windows Server 2019.
- Развёртывание сервисов с помощью Docker.
- Сбор показаний виртуальных датчиков температуры и влажности.
- Автоматическая передача данных на CTRL-01 и DB-01.
- Управление вентилятором с помощью Node-RED.
- Хранение показаний и событий в базе данных SQLite.

# 🌐 Практическая работа №2. Настройка виртуальной сети

Цель: настроить сетевое оборудование, VLAN и маршрутизацию.

Выполнено:
- Добавлены Cisco SW и Cisco RTR.
- Подготовлены виртуальные машины РЕД ОС 8 и Windows Server 2019.
- Созданы три VLAN.
- Настроены access- и trunk-порты.
- Настроены шлюзы для VLAN.
- Выполнена IP-адресация с маской /26.
- Проверена связь между рабочей станцией и серверами.

Результат: создана офисная сеть с разделением на VLAN и маршрутизацией между подсетями.

# 📡 Практическая работа №4. Node-RED и виртуальные датчики

Цель: развернуть Node-RED и настроить сбор показаний виртуальных датчиков.

Выполнено:
- Запущен Node-RED через Docker Compose на IOT-01.
- Настроен доступ к интерфейсу через порт 1880.
- Создан датчик температуры TEMP-01.
- Создан датчик влажности HUM-01.
- Настроена генерация показаний каждые 5 секунд.
- Настроена передача данных методом HTTP POST.
- Настроен приём данных на CTRL-01.

Параметры датчиков:

| Датчик | Назначение | Единица |
|---|---|---|
| TEMP-01 | Температура | °C |
| HUM-01 | Влажность | % |

Результат: виртуальные датчики автоматически формируют показания и передают их на CTRL-01.

!Node-RED

# 🌡️ Практическая работа №5. Автоматическое управление вентилятором

Цель: настроить автоматическое управление вентилятором по температуре.

Выполнено:
- Создана логика проверки температуры.
- Настроены состояния FAN ON и FAN OFF.
- При температуре выше 30 °C вентилятор включается.
- При температуре ниже 30 °C вентилятор выключается.
- Команды передаются на CTRL-01 по HTTP POST.
- Проверена работа обоих состояний.

Результат: автоматическое управление вентилятором FAN-01 работает по показаниям датчика TEMP-01.
