# Журнал практических работ — проект «Умный офис»

Номер в журнале: 19  
Среда виртуализации: GNS3  
ОС серверов: РЕД ОС 8  
Рабочая станция: Windows Server 2019

---

## Практическая работа №1. Создание виртуальной инфраструктуры

Цель: создать виртуальный прототип офисной сети в GNS3.

Выполнено:
- Создана виртуальная инфраструктура.
- Развёрнуты необходимые виртуальные машины.
- Подготовлены серверы и сетевое оборудование.

Результат: подготовлена среда для настройки сети и сервисов.

---

## Практическая работа №2. Настройка виртуальной сети

Цель: настроить VLAN, маршрутизацию и сетевое взаимодействие между узлами.

Выполнено:
- Добавлены Cisco SW и Cisco RTR.
- Созданы три VLAN.
- Настроены access- и trunk-порты.
- Настроены шлюзы и IP-адресация с маской /26.

Результат: настроена офисная сеть с VLAN и маршрутизацией между подсетями.

---

## Практическая работа №3. Docker, SSH, SCP и Nginx

Цель: подготовить серверы к запуску сервисов и развернуть веб-сервер Nginx.

Выполнено:
- Установлены Docker и Docker Compose.
- Настроено подключение по SSH.
- Выполнена передача файлов с помощью SCP.
- Запущен Nginx через Docker и Docker Compose.
- Проверена доступность веб-сервера по HTTP.

Результат: развёрнут и проверен веб-сервер Nginx.

---

## Практическая работа №4. Node-RED и виртуальные датчики

Цель: развернуть Node-RED и настроить передачу показаний датчиков на сервер CTRL-01.

Выполнено:
- Запущен Node-RED через Docker Compose.
- Созданы виртуальные датчики TEMP-01 и HUM-01.
- Настроена автоматическая генерация показаний.
- Настроена передача данных по HTTP POST.
- Подготовлен приёмник данных на сервере.

Результат: настроена передача показаний температуры и влажности на управляющий сервер.

---

## Практическая работа №5. Автоматическое управление вентилятором

Цель: настроить автоматическое управление вентилятором по показаниям датчика температуры.

Выполнено:
- Создана логика управления вентилятором в Node-RED.
- Настроены команды включения и выключения.
- Настроена отправка команд на сервер.
- Проверено сохранение событий управления в базе данных.

Результат: настроено автоматическое управление вентилятором FAN-01 по показаниям TEMP-01.

---

## Практическая работа №6. Интеграция базы данных SQLite

Цель: настроить сохранение показаний датчиков и событий управления в базе данных SQLite на сервере DB.

Выполнено:
- Установлены Docker, Docker Compose и SQLite3.
- Создана база данных с таблицами для показаний датчиков и событий исполнительных устройств.
- Настроен запуск сервиса через Docker Compose.
- Настроена передача данных на сервер DB по HTTP.
- Проверено наличие записей в базе данных.

Результат: настроено хранение показаний датчиков TEMP-01 и HUM-01, а также событий управления вентилятором FAN-01.
