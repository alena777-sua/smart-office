## Запись 1. Создание виртуальной сети в GNS3

### Выполненные действия

- Создан проект виртуальной сети офиса в GNS3.
- Добавлены Cisco SW и Cisco RTR.
- Добавлены четыре виртуальные машины РЕД ОС 8.
- Добавлена виртуальная машина Windows Server 2019.
- Созданы три VLAN на коммутаторе.
- Настроены access-порты и trunk-соединение.
- Настроены шлюзы VLAN на маршрутизаторе.
- Выполнена настройка IP-адресации с маской /26.

### Проверка

Проверена доступность:
- WIN-01 → IOT-01.
- WIN-01 → серверы РЕД ОС.
- IOT-01 → серверы РЕД ОС.

### Результат

Создана виртуальная сеть офиса. Настроены VLAN, маршрутизация и сетевые подключения.

## Запись 3. Настройка Node-RED

### Выполненные действия

- На IOT-01 запущен Node-RED через Docker Compose.
- Настроен доступ к Node-RED с компьютера WIN-01.
- Используется порт 1880.
- Созданы два виртуальных датчика:
  - TEMP-01 — температура.
  - HUM-01 — влажность.
- Настроена генерация случайных значений.
- Установлен интервал формирования показаний — 5 секунд.

### Настройка потока

Создан поток Node-RED:

text Inject → Change → HTTP Request → Debug
Используемые узлы:

- Inject — запуск формирования показаний.
- Change — настройка параметров сообщений и случайных значений.
- HTTP Request — отправка данных на CTRL-01.
- Debug — просмотр ответов сервера.

### Результат

Node-RED запущен. Виртуальные датчики температуры и влажности формируют случайные показания автоматически.

## Запись 4. Настройка приёмника данных на CTRL-01

### Выполненные действия

- Подготовлен приёмник данных на CTRL-01.
- Создан файл receiver.js.
- Создан файл compose.yml.
- Запущен контейнер ctrl-receiver-1.
- Настроен приём HTTP POST-запросов.
- Настроен приём JSON-данных от виртуальных датчиков.

### Использованные команды

bash docker compose up -d
docker compose ps
### Проверка приёмника

Проверен HTTP-адрес:

bash curl -i http://127.0.0.1:8080/health
Получен ответ:

text HTTP/1.1 200 OK
{"status":"ok"}
### Проверка получения показаний

Для просмотра поступающих данных использовалась команда:

bash docker logs -f --tail 20 ctrl-receiver-1
В журнале приёмника появились показания обоих датчиков:

- TEMP-01 — температура в °C.
- HUM-01 — влажность в %.

### Результат

Приёмник CTRL-01 успешно получает и записывает показания виртуальных датчиков TEMP-01 и HUM-01.

## Запись 5. Проверка взаимодействия IOT-01 и CTRL-01

### Выполненные действия

- Проверена связь между IOT-01 и CTRL-01.
- Проверена отправка данных методом HTTP POST.
- Проверен формат JSON.
- Проверена автоматическая генерация случайных значений.
