# Журнал практических работ — проект «Умный офис»

Номер в журнале: 19  
Среда виртуализации: GNS3  
ОС серверов: РЕД ОС 8  
Рабочая станция: Windows Server 2019

---

# Практическая работа №1. Создание виртуальной инфраструктуры

Цель: создать виртуальный прототип офисной сети в GNS3.

Выполнено:
- Создана виртуальная инфраструктура.
- Развёрнуты необходимые виртуальные машины.
- Подготовлены серверы и сетевое оборудование.

Результат: подготовлена среда для последующей настройки сети и сервисов.

---

# Практическая работа №2. Настройка виртуальной сети в GNS3

Цель: настроить VLAN, маршрутизацию и связь между рабочей станцией и серверами.

Выполнено:
- Добавлены Cisco SW и Cisco RTR.
- Подготовлены виртуальные машины РЕД ОС 8 и Windows Server 2019.
- Созданы три VLAN.
- Настроены access- и trunk-порты.
- Настроены шлюзы и IP-адресация с маской /26.

Проверка: проверялась связность WIN-01 с серверами и IOT-01.

Результат: сформирована офисная сеть с VLAN и маршрутизацией между подсетями.

---

# Практическая работа №3. Docker, SSH, SCP и Nginx

Цель: подготовить серверы к запуску сервисов и развернуть Nginx.

Выполнено:
- Установлены Docker и Docker Compose на CTRL-01, DB-01 и IOT-01.
- Настроено подключение по SSH.
- Выполнена передача тестового файла с помощью SCP.
- Запущен Nginx через docker run и Docker Compose.
- Проверялась доступность веб-сервера по HTTP.

Результат: развёрнут тестовый веб-сервер Nginx.

---

# Практическая работа №4. Node-RED и виртуальные датчики

Цель: развернуть Node-RED и настроить передачу показаний датчиков на CTRL-01.

Выполнено:
- Node-RED запущен через Docker Compose на IOT-01.
- Настроен веб-интерфейс на порту 1880.
- Подготовлены датчики TEMP-01 и HUM-01.
- Настроена генерация показаний.
- Настроена передача данных по HTTP POST.
- Подготовлен приёмник на CTRL-01.

Параметры датчиков:

| Датчик | Назначение | Единица | Зона |
|---|---|---|---|
| TEMP-01 | Температура | °C | server_room |
| HUM-01 | Влажность | % | work_area |

Результат: подготовлена передача показаний датчиков на управляющий сервер.

---

# Практическая работа №5. Автоматическое управление вентилятором

Цель: настроить автоматическое управление вентилятором по показаниям датчика температуры TEMP-01.

Выполнено:
- Настроена проверка температуры с помощью switch.
- Созданы ветки FAN ON и FAN OFF.
- Настроены отдельные узлы change.
- Подготовлена отправка команд на CTRL-01 через HTTP POST.
- Добавлен debug для проверки результата.

Условие: выше 30 °C — вентилятор включается (ON), ниже 30 °C — выключается (OFF).

Результат: подготовлена логика автоматического управления вентилятором по показаниям датчика температуры. Проверка HTTP-приёмника остаётся незавершённой.
